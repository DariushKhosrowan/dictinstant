Install in one command

On Debian / Ubuntu, add the dictinstant APT repository and install — done.

$ curl -fsSL https://raw.githubusercontent.com/amirhosseineslami/dictinstant/main/scripts/apt-setup.sh | sudo bash
$ sudo apt update
$ sudo apt install -y dictinstant
$ dictinstant # opens http://127.0.0.1:8123 in your browser
No APT? Download the package directly
$ curl -fsSL https://github.com/amirhosseineslami/dictinstant/releases/latest/download/dictinstant.deb -o /tmp/dictinstant.deb
$ sudo dpkg -i /tmp/dictinstant.deb
Or run in any browser — nothing to install

Frequently asked questions

Why does dictinstant show many definitions instead of one?

Because one flat definition rarely teaches a word well. Different dictionaries phrase a meaning differently, and the phrasing that clicks is personal. dictinstant shows several independent definitions side by side so you pick the one that makes it stick.

Where do the definitions and pictures come from?

Definitions come from the Free Dictionary API and Wiktionary — two independent, freely licensed sources. Pictures come from Wikimedia Commons. All sources are free and open, and each card names its source.

How do I install dictinstant?

On Debian/Ubuntu, add the APT repository and run sudo apt install dictinstant. A direct .deb download is also available from GitHub Releases. The app can also run in any browser with no install at all.

Are my chosen definitions saved?

Yes. When you tap “Choose this” on a definition, it is saved to your device and shown in the My chosen meanings panel, ready for review — even after you close and reopen the app.

Is dictinstant free?

Yes. dictinstant is free and open source under the MIT license, and relies on free data sources.
